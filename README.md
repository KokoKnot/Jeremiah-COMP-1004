GameTime Assistant

Overview

The GameTime Assistant is a web application designed specifically to help users efficiently manage their time devoted to gaming and their daily schedules. The application allows users to log in, set limits for their games, schedule important events, and notify them once the allocated gaming time has already elapsed.

Features

User Authentication: Log in to access personalized settings and schedules.

Gaming-Time Management: Add games and set time limits for playing the game.

Live Countdown Timer: Alerts users when the time is up for games by counting down the remaining time in-game.

Schedule Management: Add and view upcoming events with time allocations.

Persistent Data Storage: The gaming sessions and schedules are stored in local storage.

Reset Functionality: Clear all saved data when desired.

Technology Used

Frontend: HTML, CSS, JavaScript

Storage: Local Storage for storing user data 

Alerts & Notifications: JavaScript-based alerts for reminders
Using

Log in to access your personalized gaming and scheduling dashboard.

You should enter your games and give a time limit for each session.

Track your current gaming time and upcoming schedule.

The countdown timer will count how much game time is left.

Alert you when your time is up for gaming.

Use the reset button to clear all stored data.
